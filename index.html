Projects

ShopSphere — E-Commerce Analytics Dashboard

Power BI · DAX · Excel

An interactive Power BI report built on a star-schema model, sitting on top of a two-year sample retail dataset — roughly 2,100 orders, 900 customers and ₹7.2 Cr in revenue. Past the usual revenue, orders and region KPIs, it calls out the trouble spots: the category losing the most margin, the most-returned product, and 45 items that had slipped below their reorder point — a short list of exactly where to fix pricing, curb returns and dodge stock-outs.

View Live Dashboard

Pardarshita — Railway Reservation System

Python · Streamlit · SQL

Pardarshita ("transparency") is a railway ticket-booking app I built in Python with a Streamlit front end over a SQL database. It behaves like the real thing: live bookings, plus a first-in-first-out waitlist so seats go out in the exact order people queued — no line-jumping. A separate admin view runs train schedules, seat availability and live PNR status.
